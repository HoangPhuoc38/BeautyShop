# Local payment assets

`bank-qr.jpg` is intentionally ignored by Git because it may contain a personal bank account QR code.

For a local demo, place your own authorized QR image at:

```text
frontend/assets/bank-qr.jpg
```

Do not commit a personal QR image or account details to a public repository. If the QR asset is missing after cloning, configure your own image before demonstrating the payment page.
